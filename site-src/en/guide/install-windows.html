The Windows version is a single self-contained program. It runs on Windows 10 and 11 (x64) and does not need .NET or anything else installed. You need Claude Code (the CLI) or the Claude desktop app on the same PC, since the overlay shows their sessions.

Pick a download

There are two ways to get it, and both are the same app:

  • ClaudeSessionOverlay.exe is the portable version. It is one file; put it in any folder and double-click it. Nothing is installed, and deleting the file removes it.
  • ClaudeSessionOverlay-Setup.exe is the installer. It installs into %LOCALAPPDATA%\Programs without asking for administrator rights, adds a Start menu shortcut, and lets you tick two options during setup: Start with Windows and Add the session-hud mod to Claude Code. Uninstalling removes both.

The release page also has a zip with the exe, the README and the mod folder.

The SmartScreen warning

The app is not code-signed, so the first time you run it Windows SmartScreen may show "Windows protected your PC". Click More info, then Run anyway. You only have to do this once. The full source is on GitHub if you would rather build it yourself (see below).

First launch

On first launch the overlay asks whether to start with Windows. You can change your answer later from the tray icon's menu (Start with Windows). The overlay appears in the corner of the screen; drag it wherever you like and it will remember the spot.

Useful controls:

  • Tray icon: left-click to show or hide the overlay. Its menu turns sound and voice alerts on or off, lets you hear a sample alert, and resets the window position.
  • Right-click the header line: theme, language (English or Korean), collapse to one line, show sessions you already marked as seen, or hide to the tray.
  • The button at the bottom switches between dark and light themes.

Optional: the session-hud mod

The overlay works on its own. The bundled Claude Code mod adds per-session cost, usage-limit reset times, a compact button (⇣) on each row, and a one-line HUD above Claude Code's prompt. The installer can set it up for you. To do it by hand, point CLAUDE_CODE_PLUGIN_DIRS at the mod folder in ~/.claude/settings.json:

{
  "env": { "CLAUDE_CODE_PLUGIN_DIRS": "C:\\path\\to\\claude-overlay\\mod\\session-hud" }
}

Claude Code sessions you start after that load the mod. Sessions that were already running keep going without it until you restart them.

Troubleshooting switches

Two command-line options help when something looks wrong:

  • ClaudeSessionOverlay.exe --demo shows the overlay with made-up sessions, so you can check the layout and themes without running Claude Code. Add --theme light or --lang ko to try those.
  • ClaudeSessionOverlay.exe --dump writes what the overlay currently sees to ~/.claude/session-hud/dump.txt. Attach that file if you open an issue.

If a session does not appear, check that it is a live Claude Code process: the overlay lists sessions from ~/.claude/sessions/, which Claude Code writes while a session is running.

Building from source

With the .NET 9 SDK installed:

git clone https://github.com/jsuk10/claude-overlay.git
cd claude-overlay
dotnet publish app -c Release -o bin
.\bin\ClaudeSessionOverlay.exe
