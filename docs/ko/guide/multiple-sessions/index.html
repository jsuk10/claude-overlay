클로드 코드 세션 여러 개를 동시에 돌릴 때 놓치지 않는 법

고친 날: 2026년 10월 20일

Claude Code 세션을 두세 개, 많게는 다섯 개씩 나란히 돌리면 일이 확실히 빨라집니다. 하나는 리팩터링하고, 하나는 테스트를 쓰고, 하나는 버그를 뒤집니다. 문제는 주의력입니다. 세션은 권한을 물으며 멈추고, 내가 딴 곳을 보는 사이 끝나고, 조용히 컨텍스트를 채웁니다. 터미널 탭 몇 개와 데스크톱 앱 창을 오가다 보면, 어떤 세션이 "예" 한마디를 30분째 기다리고 있었다는 걸 뒤늦게 알게 됩니다.

알아야 할 상태는 셋

오버레이는 살아 있는 세션을 세 가지 상태로 나눠 항상 위에 뜬 목록 하나에 보여 줍니다.

  • 작업 중: 모델이 일하고 있습니다. 아직 내가 할 일은 없고, 얼마나 오래 돌았는지가 함께 보입니다.
  • 입력 대기: 권한 확인이나 질문 때문에 나를 기다립니다. 놓쳤을 때 시간이 가장 많이 새는 상태입니다.
  • 끝났지만 아직 안 본 세션: 차례를 마쳤는데 그 뒤로 내가 들여다보지 않았습니다.

이미 확인한 세션은 목록에서 빠져서 목록이 짧게 유지됩니다. 줄을 눌러 열거나, 데스크톱 앱에서 그 세션 창으로 가거나, 오른쪽 클릭 메뉴에서 확인 처리하면 본 것으로 칩니다. 무슨 일이 있어도 보이게 두고 싶은 세션에는 별을 달면 됩니다. ★ 즐겨찾기는 항상 목록에 남습니다.

귀로 듣는 알림

목록은 쳐다볼 때만 쓸모가 있습니다. 그래서 상태가 바뀌면 짧은 소리와 함께 한마디를 읽어 줍니다. 세션이 끝나면 "my-repo 작업 종료", 기다리기 시작하면 "my-repo 확인 필요", 컨텍스트가 90%를 넘으면 컨텍스트 경고입니다. Windows에서는 기본 음성 합성을, macOS에서는 say로 자연스러운 목소리(한국어는 Yuna 같은)를 고릅니다. 소리와 음성은 트레이 메뉴에서 따로 끌 수 있고, 화면이 잠겼거나 절전 중이거나 모니터가 꺼져 있으면 울리지 않아서 돌아왔을 때 알림이 쌓여 있지 않습니다.

누르면 그 창으로

세션 줄을 누르면 오버레이가 그 세션을 앞으로 가져옵니다. CLI 세션이면 그 세션이 돌고 있는 터미널 창을 찾습니다. 데스크톱 앱 Code 탭 세션이면 앱에서 그 세션을 열고, 이미 분할 화면에 떠 있으면 배치를 바꾸지 않은 채 그 화면의 입력창으로 커서를 옮깁니다. macOS에서는 Terminal이나 iTerm2의 세션이면 정확히 그 탭으로 갑니다.

나머지는 오른쪽 클릭 메뉴에 있습니다. 열기, 확인 처리, 즐겨찾기, 폴더 열기.

비슷한 세션 구분하기

병렬 세션은 같은 저장소의 복제본이나 워크트리에서 도는 경우가 많고, 그러면 폴더 이름이 다 같습니다. 오버레이는 경로를 드라이브와 마지막 두 폴더로 줄여 C:\…\work\app, D:\…\work\app처럼 보여 주므로, 드라이브가 다른 두 체크아웃이 똑같아 보이지 않습니다. 데스크톱 앱에서 시작한 세션은 맨 폴더 이름 대신 세션 제목이 나옵니다.

백그라운드 작업은 부모 밑으로

Claude Code는 백그라운드 서브에이전트, 백그라운드 셸, 파생 세션을 따로 띄울 수 있습니다. 이걸 전부 한 줄씩 늘어놓으면 정작 봐야 할 세션이 묻히니, 오버레이는 이들을 시작한 세션 밑에 ▸ 3 같은 작은 칩으로 접어 둡니다. 아직 뭐가 돌고 있는지 보고 싶을 때 칩을 누르면 펼쳐집니다.

방해되지 않게

항상 위에 뜨는 창은 그 자리를 차지할 값을 해야 합니다. 오버레이는 게임이나 영상 같은 전체 화면 앱이 앞에 있으면 숨고, 오른쪽 클릭 메뉴로 머리 줄만 남기고 접을 수 있고, 트레이로 내릴 수 있고, 놓아 둔 자리를 기억합니다. Windows 시작이나 맥 로그인 때 같이 켜지게 해 두면, 첫 세션을 열 때 이미 목록이 떠 있습니다.

결국 흐름은 단순해집니다. 세션을 띄워 두고 다른 일을 하다가, 화면 구석을 힐끗 보거나 알림 소리를 듣고 다음에 손볼 세션으로 가면 됩니다.

무료 오픈소스(MIT)입니다. Windows 10/11, macOS 11 이상.

다른 가이드

  • 클로드 코드 컨텍스트 사용량 확인하고 자동 압축 시점 미리 보기컨텍스트 창이 무엇인지, Claude Code가 언제 대화를 자동 압축하는지, 내 모델의 압축 기준을 계산하는 법, 세션 여러 개의 컨텍스트를 한꺼번에 지켜보는 법을 정리했습니다.
  • 클로드 주간·5시간 사용량 한도, 남은 양 확인하는 법Claude 구독 요금제는 5시간 창과 주간 창 두 가지로 사용량을 잽니다. 두 한도가 Claude Code 세션과 어떻게 맞물리는지, 작업하면서 둘 다 계속 보는 법을 정리했습니다.
  • Windows 설치: 실행 파일과 설치 파일, SmartScreen 경고, session-hud ModWindows에서 어떤 파일을 받을지, SmartScreen 경고를 넘기는 법, Windows 시작 시 실행, Claude Code에 session-hud Mod 넣기, 문제가 있을 때 쓰는 명령줄 옵션까지 차례대로 정리했습니다.
  • macOS 설치: 처음 실행 경고 넘기기, 메뉴 막대와 위젯 설정Apple Silicon·Intel 맥에 설치하는 법, '열 수 없습니다' 경고를 넘기는 법, 메뉴 막대 항목과 알림 센터 위젯, macOS 26 제어 센터 컨트롤까지 정리했습니다.
  • 클로드 세션 오버레이가 내 컴퓨터에서 읽는 것, 절대 건드리지 않는 것오버레이는 Claude Code와 Claude 데스크톱 앱이 원래 남기는 파일만 읽습니다. 무엇을 읽고 무엇을 쓰는지 파일 단위로 정리하고, 네트워크 요청을 보내지 않고 로그인 정보를 읽지 않는 이유를 적었습니다.
