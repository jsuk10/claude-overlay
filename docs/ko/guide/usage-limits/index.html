클로드 주간·5시간 사용량 한도, 남은 양 확인하는 법

고친 날: 2026년 10월 20일

API 키가 아니라 Claude 구독으로 Claude Code를 쓰고 있다면 사용량은 두 창에서 동시에 잽니다. 5시간 세션 한도와 주간 한도입니다. 둘 중 하나라도 다 쓰면 초기화될 때까지 작업이 멈춥니다. 세션을 여러 개 돌리면 특히 놓치기 쉽습니다. 세션 창은 저마다 자기 대화만 보여 주는데, 한도는 계정 전체에 붙어 있기 때문입니다.

한도는 둘, 계정은 하나

5시간 한도는 첫 메시지를 보낸 때부터 다섯 시간 동안의 창이고, 다섯 시간이 지나면 초기화됩니다. 몰아서 일하는 오후에 부딪히는 건 대개 이쪽입니다. 주간 한도는 그보다 큰 예산으로 일주일에 한 번 초기화되고, 며칠 연달아 많이 쓰면 따라잡힙니다.

Claude Code에서 중요한 점은 모든 세션이 같은 주머니에서 꺼내 쓴다는 것입니다. 세션 세 개를 나란히 돌리면 5시간 예산이 대략 세 배 빨리 줄어듭니다. 터미널 세션과 Claude 데스크톱 앱 Code 탭 세션도 똑같이 셉니다. 그래서 "얼마나 남았지?"는 계정 단위의 질문이고, 세션 창 하나로는 답이 나오지 않습니다.

숫자는 어디서 보나

Claude 데스크톱 앱은 5분쯤마다 요금제 사용량을 데이터 폴더(Windows는 %APPDATA%\Claude, macOS는 ~/Library/Application Support/Claude/)의 plan-usage-history.json 파일에 기록합니다. 오버레이는 이 파일의 가장 최근 값을 읽어 이렇게 보여 줍니다.

  • 주간 사용량은 오버레이 맨 위 머리 줄에
  • 5시간 세션 한도는 맨 아래 줄에 %와 색 막대로

마우스를 올리면 정확한 값이 나옵니다. 데스크톱 앱이 아직 아무것도 기록하지 않았다면 오래된 값이나 지어낸 값을 보여 주는 대신 맨 아래 줄에 "Claude 데스크톱 앱이 사용량을 기록하면 표시됩니다"라고 적습니다. 데스크톱 앱은 설치하고 로그인만 해 두면 되고, 앞에 띄워 둘 필요는 없습니다.

session-hud Mod로 초기화 시각까지

선택 사항인 session-hud Mod를 설치하면 출처가 하나 더 생깁니다. Claude Code가 답을 받을 때마다 함께 오는 사용량과 각 한도가 초기화되는 시각을 넘겨줍니다. Mod가 있으면 맨 아래 줄이 5시간 세션 한도 62% 사용 · reset 1시간 40분처럼 바뀌어, 더 밀어붙일지 쉴지 정하기 쉽습니다.

두 출처가 다 있으면 오버레이는 한도마다 따로 가장 최근 값을 고릅니다. 한도의 창 길이보다 오래된 값은 버립니다. 여섯 시간 전에 잰 5시간 값은 그사이 초기화됐으니 지금에 대해 아무것도 말해 주지 않기 때문입니다.

macOS: 메뉴 막대와 위젯

맥에서는 오버레이 창 밖에서도 같은 숫자가 보입니다. 메뉴 막대의 ✻ 옆에는 5시간 한도가 75%를 넘으면 그 %가 붙습니다. 그 전까지는 조용하다가 신경 써야 할 때만 나타나는 셈입니다. 메뉴를 열면 주간·5시간 사용량이 모두 나옵니다. 작은 위젯은 세션 수 옆에 5시간 한도를 보여 주고, 큰 위젯과 아주 큰 위젯은 두 한도를 막대로 그립니다.

한도를 오래 쓰는 법

사용량은 모델이 얼마나 읽고 쓰느냐로 정해지니, 컨텍스트를 아끼는 습관이 한도도 아낍니다. 파일이나 로그는 필요한 부분만 달라고 하고, 관련 없는 일은 거대한 대화를 끌고 가기보다 새 세션으로 시작하고, 더 이상 지켜보지 않는 세션은 멈추세요. 자리를 비운 사이에도 백그라운드 작업을 돌리는 세션은 같은 주머니에서 계속 꺼내 씁니다.

5시간 숫자를 화면 구석에 띄워 두면 한도가 깜짝 놀랄 일이 아니라 계획할 거리가 됩니다. 초기화까지 두 시간 남았는데 80%라면, 큰 일을 새로 벌이기보다 지금 하던 일을 마무리하는 게 맞다는 걸 바로 알 수 있습니다.

다른 가이드

  • 클로드 코드 컨텍스트 사용량 확인하고 자동 압축 시점 미리 보기컨텍스트 창이 무엇인지, Claude Code가 언제 대화를 자동 압축하는지, 내 모델의 압축 기준을 계산하는 법, 세션 여러 개의 컨텍스트를 한꺼번에 지켜보는 법을 정리했습니다.
  • 클로드 코드 세션 여러 개를 동시에 돌릴 때 놓치지 않는 법Claude Code 세션을 여러 개 띄우면 빠르지만, 하나가 권한 확인에서 20분씩 멈춰 있기도 합니다. 세션마다 상태를 한눈에 보고, 내 차례가 오면 알림을 받고, 눌러서 바로 그 세션으로 가는 법.
  • Windows 설치: 실행 파일과 설치 파일, SmartScreen 경고, session-hud ModWindows에서 어떤 파일을 받을지, SmartScreen 경고를 넘기는 법, Windows 시작 시 실행, Claude Code에 session-hud Mod 넣기, 문제가 있을 때 쓰는 명령줄 옵션까지 차례대로 정리했습니다.
  • macOS 설치: 처음 실행 경고 넘기기, 메뉴 막대와 위젯 설정Apple Silicon·Intel 맥에 설치하는 법, '열 수 없습니다' 경고를 넘기는 법, 메뉴 막대 항목과 알림 센터 위젯, macOS 26 제어 센터 컨트롤까지 정리했습니다.
  • 클로드 세션 오버레이가 내 컴퓨터에서 읽는 것, 절대 건드리지 않는 것오버레이는 Claude Code와 Claude 데스크톱 앱이 원래 남기는 파일만 읽습니다. 무엇을 읽고 무엇을 쓰는지 파일 단위로 정리하고, 네트워크 요청을 보내지 않고 로그인 정보를 읽지 않는 이유를 적었습니다.
