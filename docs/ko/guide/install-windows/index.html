Windows 설치: 실행 파일과 설치 파일, SmartScreen 경고, session-hud Mod

고친 날: 2026년 10월 20일

Windows 버전은 그 자체로 완결된 프로그램 하나입니다. Windows 10과 11(x64)에서 돌고, .NET 같은 것을 따로 설치할 필요가 없습니다. 오버레이가 보여 주는 게 Claude Code 세션이니, 같은 PC에 Claude Code(CLI)나 Claude 데스크톱 앱이 있어야 합니다.

무엇을 받을까

받는 방법은 두 가지이고, 둘 다 같은 앱입니다.

  • ClaudeSessionOverlay.exe는 설치 없이 쓰는 실행 파일입니다. 파일 하나라 아무 폴더에 두고 더블클릭하면 됩니다. 설치되는 것이 없어서 파일을 지우면 끝입니다.
  • ClaudeSessionOverlay-Setup.exe는 설치 파일입니다. 관리자 권한 없이 %LOCALAPPDATA%\Programs에 설치하고 시작 메뉴에 바로 가기를 만듭니다. 설치하면서 Windows 시작 시 실행과 Claude Code에 session-hud Mod 넣기를 체크할 수 있고, 제거하면 둘 다 지웁니다.

릴리스 페이지에는 exe, README, Mod 폴더를 묶은 zip도 있습니다.

SmartScreen 경고

코드 서명을 하지 않은 앱이라 처음 실행하면 "Windows의 PC 보호" 창이 뜰 수 있습니다. 추가 정보를 누른 뒤 실행을 누르세요. 한 번만 하면 됩니다. 직접 빌드하고 싶다면 소스 전체가 GitHub에 있습니다(아래 참고).

처음 실행

처음 켜면 Windows 시작 시 같이 실행할지 묻습니다. 나중에 트레이 아이콘 메뉴의 Windows 시작 시 실행에서 바꿀 수 있습니다. 오버레이는 화면 구석에 뜨고, 원하는 곳으로 끌어 두면 그 자리를 기억합니다.

알아 두면 좋은 조작:

  • 트레이 아이콘: 왼쪽 클릭으로 보이기·숨기기. 메뉴에서 소리·음성 알림을 켜고 끄고, 알림을 미리 들어 보고, 창 위치를 초기화합니다.
  • 머리 줄 오른쪽 클릭: 테마, 언어(한국어·영어), 한 줄로 접기, 확인한 세션 다시 보기, 트레이로 숨기기.
  • 맨 아래 버튼: 다크·라이트 테마 바꾸기.

선택: session-hud Mod

오버레이는 혼자서도 동작합니다. 함께 들어 있는 Claude Code Mod를 넣으면 세션별 비용, 사용량 한도의 초기화 시각, 세션 줄의 압축 버튼(⇣), Claude Code 프롬프트 위의 한 줄 HUD가 더해집니다. 설치 파일에서 체크하면 대신 설정해 주고, 손으로 하려면 ~/.claude/settings.json에서 CLAUDE_CODE_PLUGIN_DIRS가 Mod 폴더를 가리키게 합니다.

{
  "env": { "CLAUDE_CODE_PLUGIN_DIRS": "C:\\path\\to\\claude-overlay\\mod\\session-hud" }
}

그 뒤에 새로 시작하는 Claude Code 세션부터 Mod가 로드됩니다. 이미 돌고 있던 세션은 다시 시작할 때까지 Mod 없이 계속 돕니다.

문제가 있을 때 쓰는 옵션

뭔가 이상해 보일 때 쓸 수 있는 명령줄 옵션이 두 개 있습니다.

  • ClaudeSessionOverlay.exe --demo는 지어낸 세션으로 오버레이를 띄웁니다. Claude Code를 돌리지 않고도 배치와 테마를 확인할 수 있고, --theme light나 --lang ko를 붙여 볼 수 있습니다.
  • ClaudeSessionOverlay.exe --dump는 지금 오버레이가 보는 내용을 ~/.claude/session-hud/dump.txt에 남깁니다. 이슈를 올릴 때 이 파일을 붙여 주세요.

세션이 목록에 안 보이면 그 세션이 실제로 살아 있는 Claude Code 프로세스인지 확인하세요. 오버레이는 Claude Code가 세션이 도는 동안 써 두는 ~/.claude/sessions/에서 세션 목록을 읽습니다.

소스에서 빌드

.NET 9 SDK를 설치한 뒤:

git clone https://github.com/jsuk10/claude-overlay.git
cd claude-overlay
dotnet publish app -c Release -o bin
.\bin\ClaudeSessionOverlay.exe

다른 가이드

  • 클로드 코드 컨텍스트 사용량 확인하고 자동 압축 시점 미리 보기컨텍스트 창이 무엇인지, Claude Code가 언제 대화를 자동 압축하는지, 내 모델의 압축 기준을 계산하는 법, 세션 여러 개의 컨텍스트를 한꺼번에 지켜보는 법을 정리했습니다.
  • 클로드 주간·5시간 사용량 한도, 남은 양 확인하는 법Claude 구독 요금제는 5시간 창과 주간 창 두 가지로 사용량을 잽니다. 두 한도가 Claude Code 세션과 어떻게 맞물리는지, 작업하면서 둘 다 계속 보는 법을 정리했습니다.
  • 클로드 코드 세션 여러 개를 동시에 돌릴 때 놓치지 않는 법Claude Code 세션을 여러 개 띄우면 빠르지만, 하나가 권한 확인에서 20분씩 멈춰 있기도 합니다. 세션마다 상태를 한눈에 보고, 내 차례가 오면 알림을 받고, 눌러서 바로 그 세션으로 가는 법.
  • macOS 설치: 처음 실행 경고 넘기기, 메뉴 막대와 위젯 설정Apple Silicon·Intel 맥에 설치하는 법, '열 수 없습니다' 경고를 넘기는 법, 메뉴 막대 항목과 알림 센터 위젯, macOS 26 제어 센터 컨트롤까지 정리했습니다.
  • 클로드 세션 오버레이가 내 컴퓨터에서 읽는 것, 절대 건드리지 않는 것오버레이는 Claude Code와 Claude 데스크톱 앱이 원래 남기는 파일만 읽습니다. 무엇을 읽고 무엇을 쓰는지 파일 단위로 정리하고, 네트워크 요청을 보내지 않고 로그인 정보를 읽지 않는 이유를 적었습니다.
